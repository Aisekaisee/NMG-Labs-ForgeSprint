# SEO Command Center — Forge Sprint 01

A comprehensive local SEO audit and automated fixing workspace. This project ingests Screaming Frog website crawl exports (such as `internal_all.csv`), automatically detects critical SEO issues based on a strict rulebook, uses a local LLM (via Ollama) to recommend intelligent metadata rewrites and redirect maps, and provides a beautiful local dashboard + client-ready reports.

---

## 🚀 Key Features

* **Complete SEO Rulebook Detector:** Full implementation of all 17 detection rules (e.g., missing/duplicate/long/short titles and metas, missing H1s, broken links, redirect chains, thin content, slow pages, and orphan pages).
* **AI-Powered Fixes:** Intelligent metadata (Title & Meta Description) rewriting using local LLM models (e.g., `qwen3.5:9b`), complete with automated retries and strict length limit guidelines.
* **Smart Redirect Mapping:** Analyzes 404/broken links and builds a redirection mapping to the closest live matching page or site homepage.
* **Interactive Live Dashboard:** A local web cockpit served at `http://localhost:7700` showing real-time crawl overview, issue lists, and proposed fixes.
* **Automated Client Reporting:** Generates self-contained, clean `outputs/report.json` and a client-ready styled `outputs/report.html` email/presentation template.
* **Process Tracking & Audit Logging:** Custom session export scripts and hook integrations to track every agent decision, tool call, and prompt iteration.

## 🛠️ Quick Start & Usage

### 1. Prerequisites
Ensure you have Python 3.10+ installed. You also need a local instance of [Ollama](https://ollama.com/) running with the default model (`qwen3.5:9b`):
```bash
ollama run qwen3.5:9b
```

*(Optional) Install MCP if you plan on integrating tools into your editor/environment:*
```bash
pip install mcp
```

### 2. Running the Headless Pipeline
To execute the pipeline end-to-end (ingest, audit, fix, recommend, and generate reports), run:
```bash
python seo-command-center/run.py sample-export/
```

This will run the detection and fixing scripts, write output files to `seo-command-center/outputs/`, and launch the web server.

### 3. Accessing the Live Dashboard
Open your web browser and navigate to:
[http://localhost:7700](http://localhost:7700)

Here, you can view the issues, see live updates, and inspect proposed fixes generated by the local model.

### 4. Exporting Session Transcripts
To update `agent-log.md` with your latest session transcript:
```bash
./seo-command-center/scripts/export-transcript.sh
```

## ⚙️ How the Detection & Fixing works

### Detection
The system runs deterministically on `internal_all.csv` following the pre-filters and rules defined in `rulebook.md`. It filters for `text/html` indexable 200 pages for duplicate checks and standardizes severity levels (`High`, `Medium`, `Low`).

### Metadata & Link Fixing
* **Titles/Meta Descriptions:** The pipeline isolates pages flagged for missing or poor-quality metadata and queries Ollama to rewrite them based on surrounding page details (like H1 headings or original meta tags).
* **Redirect Chains:** The detector tracks multi-hop redirects and flags the root URL of a chain.
* **404 / Broken Link Redirections:** A mapping is built to automatically route broken URLs to the closest live relative path or fallback directly to the home page using URL path segmentation.
